FOCUSFORT — An Intelligent Distraction Blocking Application for Android
FOCUSFORT is an Android application designed to help users stay focused, reduce digital distractions, and build healthier screen-time habits.
Overview
Smartphones make it easy to lose focus through frequent notifications and distracting apps. FOCUSFORT aims to support more intentional phone use with a focus-oriented experience and distraction-blocking features.

Getting Started
Prerequisites
- Android Studio
- A compatible JDK for the project's configured Android Gradle Plugin and Gradle versions
- Android SDK components required by the project
Open and run
1. Clone this repository:
   git clone https://github.com/prithiviraajj-r/FOCUSFORT-AN-INTELLIGENT-DISTRACTION-BLOCKING-.git
2. Open Android Studio.
3. Select Open and choose the cloned project folder.
4. Allow Gradle to sync and install any required SDK components.
5. Select an Android emulator or connected Android device.
6. Run the app using Android Studio's Run action.
You can also open the project in Android Studio and use its Gradle sync and run tools to build and launch the application.
